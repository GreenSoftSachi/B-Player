# 👑 B-Player

**B-Player** is the Ultimate Hybrid Android Media Player combining the best of **libmpv**, **Jetpack Compose (Material 3)**, and the classic **MX Player** experience.

## 🚀 Features
- 🎬 **`libmpv` Core Playback Engine**: Zero-compromise hardware and software decoding for 4K 10-bit HEVC, Dolby Vision (Profile 8.1), HDR10+, AV1, VP9, and ProRes.
- 🔊 **Advanced Multi-Channel Audio**: 6-Channel (5.1 Surround) HE-AAC, AC-3, E-AC-3 Dolby Atmos, DTS-HD, TrueHD, with dialogue-enhanced stereo downmix.
- 💬 **`libass` Subtitle Engine**: Perfect rendering of styled, animated, and karaoke `.ass` / `.ssa` subtitles, dual subtitles, and external subtitle loading.
- 🎨 **Jetpack Compose Material 3 UI**: Fluid sliding bottom sheets, playback history tracking, sleep timer, speed chips, smooth PiP.
- 🖐️ **Iconic MX Player Gestures**: Swipe for brightness & volume, horizontal scrubbing, double tap seek, pinch to zoom.
- 🌐 **Network Streaming**: Direct streaming from SMB, Windows Network Share, FTP, and WebDAV.
